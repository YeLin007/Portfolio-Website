YL's Travel List

React Component Design State Management

YL's Travel List is a React web application that helps travelers create and manage packing lists efficiently. Users can add items with quantities, mark them as packed, track their packing progress with real-time statistics, and clear their list when needed. The app demonstrates clean component architecture and effective state management patterns.

Overview

This Travel Packing App was built to solve the common problem of forgetting essential items when traveling. The app provides a simple, intuitive interface where users can build their packing list by adding items with specific quantities, track what they've already packed, and see their overall packing progress.

The application is structured with five main components: Logo (branding header), Form (add items), PackingList (displays all items), Item (individual item component), and Stats (progress footer). All state is managed at the App level and passed down through props, following React best practices.

Project Details

  • Role: Developer
  • Type: React web application
  • Tech Stack: React (Hooks), JavaScript, CSS

Key Features

Simple yet powerful packing list functionality.

Add Items with Quantity

Users can add packing items with a quantity selector (1-99) and description field. The form includes validation to prevent empty submissions and automatically resets after adding an item. Each item gets a unique ID based on timestamp.

Toggle Packed Status

Each item has a checkbox to mark it as packed or unpacked. Packed items display visual feedback with different styling (strikethrough text, "Packed" pill badge). This uses immutable state updates with the map() function.

Real-time Progress Tracking

The Stats footer displays live packing progress showing "X / Y items packed" and a percentage (e.g., "You are 75% ready for your trip"). Statistics update instantly as users check/uncheck items.

Delete Individual Items

Each item has a delete button (✕) that removes it from the list. The app uses the filter() method to create a new array without the deleted item, maintaining immutability principles.

Clear All Functionality

A "Clear all" button allows users to remove all items at once. The app shows a confirmation dialog before clearing to prevent accidental data loss. This button only appears when there are items in the list.

Empty State Messaging

When the list is empty, the app displays helpful messages like "Your packing list is empty. Start adding a few essentials" and "No items packed yet. Add a few things above to start tracking your packing progress."

Technical Implementation

Clean component architecture and React patterns.

Component Structure

The app is divided into 5 reusable components: Logo (header branding), Form (add items form), PackingList (list container), Item (individual list item), and Stats (progress footer). This separation of concerns makes the code maintainable and testable.

State Management

All application state (items array) is managed in the App component using useState. State is lifted to the top level and passed down through props, following the "single source of truth" principle. Handler functions are also passed as props.

Immutable Updates

All state updates use immutable patterns: spread operator for adding items, map() for toggling packed status, and filter() for deletion. This ensures React can properly detect changes and re-render efficiently.

Controlled Inputs

The form uses controlled inputs where React state drives the input values. Both the quantity selector and description field are controlled components, ensuring React is always aware of their current values.

What I Learned

Building YL's Travel List significantly improved my React development skills. Key learnings include:

  • Lifting state up to share data between sibling components
  • Passing event handlers as props to enable child components to modify parent state
  • Using immutable update patterns (spread, map, filter) for state changes
  • Creating controlled form inputs that sync with React state
  • Conditional rendering for empty states and dynamic UI elements
  • Structuring React applications with clean component architecture
  • Using unique keys (timestamp-based IDs) for efficient list rendering
